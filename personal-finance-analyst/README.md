# personal-finance-analyst — скилл для Claude Code

Персональный финансовый аналитик: разбирает банковские выписки и отвечает как консультант —
куда уходят деньги, что с этим делать и сколько это даст в рублях за год. Плюс отчёт с графиками.

Автор: Алик Завалишев · Telegram [@zavalishevs](https://t.me/zavalishevs) · бесплатно · https://github.com/zavalishev/claude-financial-skill

## Что умеет
- Читает PDF-выписки Сбера и CSV/XLSX любых банков, сверяет итоги с шапкой выписки.
- Отделяет оборот (переводы себе, вклады, погашение кредитки, наличные) от настоящих трат.
- Находит частые места, подписки, мелкие утечки, проценты по кредитке, деньги без процентов,
  траты под налоговый вычет, рост категорий («чаще» или «дороже»).
- Ищет в интернете актуальные накопительные счета, кешбэк под ваши категории, условия вычетов и ИИС.
- Собирает `report.html` с графиками: траты по месяцам, тепловая карта покупок, категории, долг по кредитке,
  «во что превратится экономия».
- `--demo 3` — делит все суммы, чтобы показать отчёт другим без своих реальных цифр.

Всё считается на вашем компьютере. Выписки никуда не отправляются.

## Установка
```bash
mkdir -p ~/.claude/skills
cp -r personal-finance-analyst ~/.claude/skills/
```
Нужен Python 3 и `pdftotext` для PDF (`brew install poppler` на Mac, `sudo apt install poppler-utils` на Linux).
Для Excel — `pip install openpyxl`.

## Как пользоваться
Откройте Claude Code в любой папке и напишите:
> Разбери мои выписки из ~/Downloads

или `/personal-finance-analyst ~/Downloads/Выписка*.pdf`.

Перед этим удалите из выписок то, что не хотите показывать даже локально, — ИИ не нужны номера карт и ФИО.

## Состав
- `SKILL.md` — методика консультанта и правила.
- `scripts/parse_statements.py` — чтение выписок и сверка итогов.
- `scripts/analyze.py` — разбор операций и все расчёты → `analysis.json`.
- `scripts/build_report.py` — отчёт с графиками → `report.html`.
- `references/category_rules.json` — правила категорий; дополняйте под свои банки.
- `references/ru-context.md` — ставки и правила вычетов на дату проверки.
- `templates/answer.md` — шаблон ответа.

Это инструмент для самостоятельного разбора, а не финансовая рекомендация.
Структура скилла сделана по образцу скиллов Anthropic (anthropics/claude-for-financial-advisors, Apache-2.0); код и методика — свои.
